# Public cutover

JW **0.12.0** consumes exact provider **0.9.0**. `jw reseed` and the request/API
defaults select `--renewal-route=refresh --refresh-check=mtime,size --postcheck=none`.
The supplied check list replaces the entire set; nonempty, unique names are
`mtime,size,mode`. Full mode compares Unix `0o7777`, not just executable state.
Links always compare literal text. This is an explicitly accepted **heuristic**,
not byte equality, physical-sharing proof, mandatory inode renewal or alias repair.

Refresh uses replacement's non-clearing native lifecycle: preserve O, create a new
same-O child, satisfy S under exact owned authority, admit D additions, adopt S
tree_state, optionally restore D, reparent only that receiving change and verify
exact native conformance. Changed/new leaves keep the existing staged required
reflink/literal-link installer. O-only retirement and kind-transition authority
remain provider-owned. Occupied unowned names still refuse even when stat-equal.

The explicit old routes remain unconditional tracked installation. Independent
`--replace-content` removes all refill candidates as well as unrelated non-admin
contents; all three selected routes then use strict create-absent S installation.
It does not silently select another native route. No default namespace clear is
introduced. Ordinary Q uses the same selected StatComparator on **every** route.

## Native executable correction, not a hidden mode check

The exact S manifest already records native regular executable expectations.
Only native `ListedTarget`s opt into `RetainedAttributes::ManifestExecutable`.
At successful retained acceptance, sync uses prepared actual target metadata.
If any `0o111` bit agrees with S's executable boolean, it issues no chmod. Otherwise
it sets/clears those bits in place while preserving other permission bits. It does
not replace the inode, reset unrelated mode bits, add a stat sweep or collect a
retained-file handoff catalog. Source validation, selection and binding stay pure;
the effect is sync-owned. Ordinary retention never gains this opt-in.

`ListedOutcome.retained_permissions_set` counts successful actual corrections,
including failure prefixes. JW preserves it before inspecting lane success and
exposes `native.retained_permissions_set` separately from installation effects.
Only successful correction credits that leaf's retained obligation. Failed
normalization cannot advance complete coverage or native adoption. Generic
Progress/Failure and ordinary wide totals remain unchanged; an intermediate broad
counter tripped the existing failure-size lint budget and was narrowed deliberately.

`--postcheck=mtime` applies to tracked and ordinary regular installations on all
routes. None is default. Source mtime and permissions are still set. No new
read-back path was added; the predecessor's actual omitted-statx syscall witness
remains applicable. Configuration is typed once per command/cohort, not parsed
inside per-leaf work. Ordinary SyncParts advances from the receiving predecessor's
version3 to provider version4, binding per-lane postchecks and comparator identity.
