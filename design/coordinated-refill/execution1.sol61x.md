## Frozen authority, not ancestor replay

[`streaming.rs`](/transfer/workspace/src/streaming.rs) implements
`SourceQualified: Policy<Context = OrdinaryRegion>` under the actual `StatKey`
comparator. The initial structural gate yields `Search`; a source-qualified Q
yields `SelectedMirror { root, admission }`.

- `SearchState` carries incremental selector automaton positions, both frozen
  ignore cursors, and narrowed native/link trie positions. Each source-directory
  descent advances one component. An ignored parent stays ignored; deeper negation
  cannot reopen it. No live ignore files, native subprocesses or payload prewalk
  enter these callbacks.
- At a real source-directory Q, shape selection settles selector, S/D ignoredness
  and both-way native/active-link overlap once. Only successful final validation
  publishes its immutable region. Selected paired, source-only, target-only,
  private replacement and removability interiors all carry that region.
- Below Q, selectors, ancestor ignoredness and native/link overlap are **not
  re-admitted**. Administration, supported kinds and actual device attributes
  remain residual guards, including on assessed equal leaves.
- Target-only candidates outside Q stay preserved: a previously selected root
  that vanished from S is not deletion authority. Unknown listing hints remain
  present-but-untyped. Known unselected source leaves can be excluded early;
  Unknown leaves reach kind resolution before shape preservation.
- Byte-named admitted interiors work without decoding their names as selectors.
  Byte-named routing directories still refuse under the existing UTF-8 selector
  grammar. Nested `.jj`/`.git` refuses even during opaque removal and preflight.
- Active links own whole names outside Q and conflict with Q admission. A loaded
  source==target private-directory declaration is not an active link. The loaded
  target spelling rules, including symlink/`..` meaning, remain unchanged.
- Missing search routes use `CreateIfNeeded`; no match creates no skeleton.
  An explicitly selected empty directory does realize its conditional ancestry.

[`ignored.rs`](/transfer/workspace/src/ignored.rs) exposes the existing component
automaton as immutable `Prefix` values. [`frozen.rs`](/transfer/workspace/src/frozen.rs)
adds serializable active rule chains and sticky exclusion to the same compiled
matcher. Its incremental answers are checked against the existing Git-oracle
precedence/ancestor corpus; there is no new ignore interpretation.

`OrdinarySource` shares the immutable compiled selector and source/native trie
across lanes. Lane-specific D rules, effective excludes, active-link indexes and
devices stay separate. `FrozenIgnores` still shares rule compilation by proven
tree **and effective excludes**, not tree alone.

### Context values and validation

`OrdinaryRegion`, `SearchState`, `Prefix` and `IgnoreState` own serializable values,
not Arc addresses or a mutable discovered-root side table. Policy identity binds
length-framed selector/native declarations, exact captured ignore-byte digests,
links and devices. The context schema is independently named/versioned.

Search values have a deterministic frozen-value checksum; selected values bind
their root to the exact frozen policy interpretation. These checksums are **not
secret authorization tokens**. They detect damaged or mismatched saved residuals
under the provider's caller-owned binding contract. Validation checks schema,
coordinates and frozen values without source I/O, selector replay or Q admission.
The test reconstructs independently allocated policies, round-trips contexts,
moves S away, accepts identical meaning and refuses changed/damaged meaning.
This does not introduce a JW resume command.

## One callable cohort and honest failures

The stable upcoming command/CLI integration surface is:

```rust,ignore
use jj_waltz_refill_engine::command::{ContextualOrdinary, ResolvedCommand};
let mut ordinary = ContextualOrdinary::default();
let report = command.execute(&mut ordinary, &mut diagnostic)?;
// execute_prepared(prepared_source, ...) uses the same adapter.
```

`ContextualOrdinary.resources` accepts caller-owned `ObservationResources` when
the caller needs explicit backend/buffer requirements. The transfer-owned API is
`sync_cohort(source, Vec<CohortLane>, resources)`; its `CohortFailure` contains the
original `anyhow::Error`, optional stable lane index and actual cursor reports.
Transfer has no dependency on command/report types in the engine.

The adapter lowers the shared source index and lane-specific frozen inputs once.
The cohort builds data-only initial cursor state before binding, then creates
**one** `Arc<SourceSession>` with the supplied resource owner and calls
`bind_with_source`. It does not first create a default source session and replace
it. Bound workspace names are stable target IDs; binding order, not lexical ID
order, controls dispatch.

The explicit loop checks every returned lane result before the group's first
application, then applies pending lanes one at a time, stopping on the first
returned failure. It settles and continues only after successful disposition.
It neither calls `drive`/`apply_many` nor filters applications by planned count.
An all-empty policy constructs no runtime and performs no traversal.

On every post-construction error, actual `cursor.reports()` populate every lane
before returning the original cause. Invalid declarations that cannot construct
a valid cursor have no invented report. The engine projects actual satisfaction
versus partial state rather than parsing diagnostic text or manufacturing zero
effects. A healthy ordinary lane can already be satisfied when another fails;
it is not a complete **command receiver** until loaded finish succeeds.

The temporary `refill_one_from` report projection remains for existing callers,
but now delegates N1 to `ContextualOrdinary`; it owns no second transfer driver.
Clear-first native establishment, producer/direct handoff, preservation barriers
and PLANNED preview remain the previously tested owners.

  identities. Both lanes see the **same actual retained `Metadata` allocation**

  of pointer identity for policy/context meaning.
- Per-lane admission/search counters: `pkg/cache` is qualified once, search

  never restart that search. The diagnostic collectors are test-only and do not
  participate in decisions or depend on callback ordering.
- Mixed missing/paired N2: per-lane clone progress, B's stale-only subtree removal,
  explicit empty-directory creation and preserved vanished-source roots.

  A first opaque application failure never starts its pending peer, even with
  reverse-lexical target IDs. A later B failure retains A's actual satisfaction
  and both lanes' already returned clone work.
- Administrative veto keeps a coupled collapse intact; failed private expansion
  discards private progress/staging while retaining visible sibling work and the
  old destination. No JW-local copier implements these transitions.
- Default Unknown versus Linux native-dirent Known observations reach distinct
  early/shape paths. Selected equal byte-named leaves still demand guard metadata.
