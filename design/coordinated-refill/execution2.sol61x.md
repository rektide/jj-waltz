## One prepared tracked-source phase

[`TrackedPhase`](../../refill/engine/src/engine/command/native/listed.rs) is owned
inside the existing native input lifetime:

- `PreparedLeafList::from_specs` constructs **full S once**, with exact file/link
  kind and `Some(executable)` for regular files; symlinks have no executable demand.
- `OwnedLeafSet` is prepared once per distinct proven O tree when normal authorized
  renewal needs it. Existing empty-child tree equivalence can share the immutable
  owner index. Clear-first and successful explicit broad clearing use one empty
  owner set with strict `CreateAbsent`; they do not gain replacement authority.
- Each receiver has a reusable `EffectBinding` with `ReflinkRequired`. One stable
  `SourceSession` shares positive source observations across the serial native calls.
  Source coordinate/binding barriers still run before each receiver; no fresh live
  donor proof or implicit donor snapshot is inserted for assumed-prepared input.
- `NativeGuard` is pure. It checks actual bound root coordinates and root inodes,
  real directory routes, normal/admin-free coordinates, supported metadata kinds
  and side-specific devices. It performs no filesystem/native I/O. Route demands
  name only their actual side. O-only/census `NotRequested` source never asks for
  source attributes. Native memberships supply ownership; equality supplies none.

The native call is `reconcile_listed(session, full_s, &[one_receiver])`. Returned
coverage is stored **before** inspecting the lane result. A successful outer
result alone is insufficient: lane success **and** actual `coverage.complete` are
required before D admission and S adoption. No flat O-minus-S deletion, local copy
loop, name-union approximation or post-failure census was added.

After all native receivers succeed, command code explicitly drops the native
inputs, memberships and capture helper before ordinary transfer. This releases
the S/O manifest indexes, effect bindings, tracked source cache and donor raw
`tree_state`. Only the compact diagnostic snapshot, saved coordinates/history and
ordinary-required S/D exclusions/rules remain; no O membership crosses that seam.

## Native protocols and retained authority

The raw tested native profile and all three `run_refill` overrides are unchanged.
Exact IDs use `commit_id_revset`; receiving `.jj`/checkout identity is never copied.
The source/saved-O barriers, history coverage/bypass, strict receiver ownership,
registration/root/repository checks and source/target local boundaries remain.

**ClearThenPopulate** retains sparse clear, unchanged recorded O, residual exact-O
refusal, then `new exact D` while sparse-empty. It performs strict full-S
`CreateAbsent`, admits D additions, adopts captured S state, optionally restores D,
and requires native diff/full-sparse/empty-child/identity conformance.

**ReplaceAuthorized** implements the selected R1–R7 sequence:

1. `new exact O` creates C as an empty same-tree child. Check parent, new change
   identity, stable receiving binding and the still-visible unchanged O change.
2. Normal execution renews O→S with `RenewOwned`, including common equal leaves
   and obsolete O retirement. Coupled collapse/expansion stays with the provider.
3. Admit D-only coordinates under installed-S/retained-local rules; only then
   adopt full S state. Matching unrelated S-only or D-only names still refuse.
4. If D≠S, `restore --from exact D` establishes D through native checkout.
5. Check C's retained identity/old parent and that it acquired no outside
   descendants; run **`rebase -r @ -d exact D`**, not branch/descendant rebase or
   skip-emptied. Only the newly created receiving change is selected.
6. Require final native tracked diff and exact-D empty single-parent child,
   full sparse, original registration/root/repository and retained C change ID.

`--replace-content` remains separate broad-clear authority after child creation.
If it fails, installation never starts; if it succeeds, the same selected route
uses strict CreateAbsent into the actually cleared namespace. A replacement route
still reparents C and is still reported as ReplaceAuthorized.

D≠S progress is **S installation work**, possibly temporary. Native D restore can
remove S-only installs or materialize D leaves from the store. There is no report
of donor sharing for every final D leaf. Tracked inode renewal is proactive;
ordinary stat-equal retention remains neither byte verification nor alias repair.

Receivers become **Partial at preservation entry**, not only native entry. A

## Ordinary diagnostics and optional execution are real

The parent's additional payload-parallel requirement is implemented, not left as

- `OrdinaryTransfer::admit` is now **mutable**. `ContextualOrdinary` admits the
  existing `transfer::Execution` before probes/source/preservation/native mutation.
  Pool construction failure therefore precedes destructive work.
- Default execution remains serial. With `payload-parallel` and enabled ordinary
  selection, one command-owned pool uses `min(available_parallelism, 4)` workers.
  Native transitions stay on the caller thread outside its scope.
- `Execution::scope` lends that pool to `sync_cohort_with_execution` once around
  joined inspection/application. The unchanged explicit peer loop still applies
  one lane at a time and stops at the first surfaced failure. There are no N1 loops,
  per-root pools, global configuration or resource values in policy/checkpoint IDs.
- Disabled selection creates no pool/runtime/source session. The original
  `sync_cohort` is a serial compatibility wrapper; the command uses the borrowed
